SwapCityClassic

      
A top-down driving game on real city streets, picked from the menu below — every road, block and building is the real place.

      
Built by Brent Shiely and Claude Code in under 14 hours of actual engineering time (spread across
        Sept 20–23, 2026, around the usual downtime): real OpenStreetMap road and building data, Minneapolis at
        full-city scale with real building heights measured from LiDAR. Every city here is a
        live street network shared with about 80 pedestrians and 16 traffic cars, in a browser, at a smooth frame rate.

      

        
        
      

      

        Technical details
        

          
Engine: Phaser 3.90 (2D WebGL/Canvas) for rendering, the camera and input; Three.js + 3d-tiles-renderer
            for the optional live Google Photorealistic 3D Tiles layer.

          
Build: Vite 8 + vite-plugin-singlefile. The offline release packs the whole game and city into one
            self-contained HTML file that runs with no server and no internet; the online build streams city tiles as you drive.

          
Map & imagery data: road network and building footprints from OpenStreetMap via the Overpass API
            (© OpenStreetMap contributors, ODbL); building heights from USGS 3DEP LiDAR (public domain); roof photos
            from USGS NAIP aerial imagery (public domain); Google's Photorealistic 3D Tiles API as an optional live online
            layer only — never cached or used offline, per its terms.

          
Scale: Minneapolis, MN is the flagship at full-city scale — 162,066 buildings (162,064 with real
            LiDAR-measured heights), 16,762 roads, 11,721 road-graph nodes, about 4,800 roof-photo tiles. Every other city
            in the menu is a 1-mile-radius excerpt around its centre, on the same engine, without LiDAR heights or roof
            photos (both Minneapolis-only data sources) — their buildings use OpenStreetMap's own height tags, or a
            guess where OSM has none.

          
Everything else: traffic, pedestrians, driving physics, collision, A* route-finding, sound and the
            rendering pipeline are hand-written JavaScript — no game-asset packages, no physics engine. 15 automated
            test suites (npm test) cover it.

          
Hosting: static hosting on Cloudflare Pages.
